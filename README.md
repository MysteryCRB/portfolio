# PERSONAL PORTFOLIO

This is my personal portfolio website—a showcase of my skills, projects, work experience, and organizational activities in Information Technology and Cyber Security. The project is designed to provide an engaging, interactive, and visually appealing online resume that reflects my passion and expertise in the field.

## Purpose

The purpose of this project is to:
- **Showcase My Professional Profile:** Present a detailed view of my background, technical and soft skills, education, and work experience.
- **Display My Projects:** Highlight a variety of projects, including cybersecurity audits, penetration testing, and various development endeavors.
- **Engage with Potential Employers and Collaborators:** Provide easy access to my CV and contact details so that recruiters and collaborators can connect with me.
- **Demonstrate Modern Web Development Techniques:** Utilize animations, interactive components, and responsive design to create a polished user experience.

## Tools & Technologies

This portfolio project was built using modern web development tools and technologies, including:
- **React:** For building dynamic and reusable UI components.
- **Tailwind CSS:** For rapid, utility-first styling.
- **lucide-react:** For crisp, modern icons.
- **Vite:** For fast development and build performance.
- **StackBlitz:** As an online development environment to prototype and deploy the project quickly.
